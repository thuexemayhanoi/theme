## What this does not prove

- Scope is "every URL the sitemaps listed at 20:57–21:15 UTC". Pages that exist but are not in a sitemap are not visited; links found only on such pages, on other sites or injected by JavaScript are unknown (the tool reads the HTML as served, not the rendered DOM). "Orphan" therefore means "no link from another sitemap page", not "unreachable".
- "Indexable" is derived from the robots meta tag, the `X-Robots-Tag` header and `robots.txt` as a GitHub runner sees them. It is not Google's index coverage; Search Console was not consulted.
- Pages come from the LiteSpeed cache like any visitor's, so a page edited minutes ago may still show its old HTML (the same cache effect described in `reports/homepage-images-2026-10-22.md`).
- Exactly 1,000 post URLs sit in one post sitemap, which is also Yoast's default limit per sitemap file. The audit follows the index, so a second post sitemap that appears with the 1,001st post is picked up automatically (nested indexes are covered by the tests).
- Exit code is success when the status is COMPLETE; a PARTIAL run exits 0 unless `--strict` is passed. Do not read a green job as COMPLETE without the status line (`summary.json`).

## Reproduce

*Actions → Read-only SEO Internal Link Graph → Run workflow* on any branch that has the v2 tool (`limit 0` = every unchecked URL; `resume_run_id` continues an earlier run). Pull requests that touch the tool only audit a 120-URL sample. No schedule exists on purpose.
